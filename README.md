# Auth System 🔑

## Overview
This project is a simple **Authentication System** built with Node.js & Express.  
It was my first backend project to practice and apply core concepts of authentication.

## Features
- User registration & login
- JWT-based authentication
- Secure password hashing with bcrypt
- Error handling & validation

## Tech Stack
- Node.js
- Express.js
- JWT
- bcrypt
- PostgreSQL (optional if you added DB integration)
